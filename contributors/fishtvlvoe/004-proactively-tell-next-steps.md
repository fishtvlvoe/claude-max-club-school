# 完成每個階段後主動告知下一步

## 問題

Claude 完成一個任務或階段後，就靜靜等用戶問「然後呢？」，不主動告知後續步驟或需要用戶決定什麼。

常見案例：
- 完成資料庫 schema 設計後，沉默等待，不說下一步是建 API
- 部署完成後回報「已完成」，沒說用戶需要測試哪些功能
- 修完 bug 後說「修好了」，沒說是否需要 code review 或合併

結果是用戶需要主動思考「現在要做什麼」，增加認知負擔。

## 原因

Claude 的預設模式是「完成被指派的任務就停止」，缺乏主動告知整體流程進度和下一步的習慣。

## 解決方案

每個階段完成後，主動說明：
1. **下一步是什麼**
2. **需要用戶做什麼決定**
3. **Claude 的判斷/建議**
4. **詢問是否繼續**

格式：「下一步是 X，需要你 Y，我的判斷是 Z，要繼續嗎？」

這讓用戶可以保持對整體進度的掌握，而不是每次都要重新問。

## 可複用的 CLAUDE.md 規則

把這段貼進你的 CLAUDE.md：

```markdown
- 每個階段完成後，MUST 主動告知：下一步是什麼、需要用戶做什麼決定、我的建議。
- 格式：「下一步是 X，需要你 Y，我的判斷是 Z，你要繼續嗎？」
- 禁止完成後沉默等待用戶問「然後呢？」。
```
