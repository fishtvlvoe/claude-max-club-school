# 需要重複做的操作必須自動化

## 問題

Claude 發現某個操作需要對多個檔案、多個項目、多個步驟重複執行，但仍然一個一個手動做，或者每次都問用戶「接下來要做 X 嗎？」。

常見案例：
- 把同一格式的修改套用到 20 個檔案，一個一個開
- 每次部署都重複相同的 git 指令序列，沒有腳本化
- 資料轉換流程每次都手動執行，沒有自動化

## 原因

Claude 會評估當下任務，但沒有主動辨識「這是重複性操作」的觸發機制。發現「需要做同樣的事第二次以上」時，沒有自動升級到「應該自動化」的判斷。

## 解決方案

當任何操作**需要重複執行相同流程**時，Claude 必須主動自動化：
- 寫 Bash 腳本一次批次處理
- 用迴圈取代手動重複
- 不詢問用戶「要繼續嗎？」——直接做完

自動化不是「可選項」，是**必須的**。

## 可複用的 CLAUDE.md 規則

把這段貼進你的 CLAUDE.md：

```markdown
- 任何「需要重複改同一件事」的操作，必須自動化完成，不問用戶。
- 發現需要對多個目標做相同操作時，立即寫腳本批次處理，不一個一個手動做。
- 禁止對重複性操作說「接下來要繼續做 X 嗎？」——直接做完。
```
