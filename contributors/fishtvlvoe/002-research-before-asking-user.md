# 不確定的事自己查，禁止叫用戶代勞驗證

## 問題

Claude 不確定某件事是否可行時，會叫用戶「試試看」或「你那邊確認一下」——把本來自己能查清楚的事情丟給用戶去驗證。

常見案例：
- 「你可以試著執行這個指令看看有沒有作用」
- 「請你打開瀏覽器看一下這個頁面是否正常」
- 「這個 API 你那邊能呼叫嗎？」

結果是 Claude 給出半成品，用戶變成 QA。

## 原因

Claude 在某些情境下預設自己「沒有辦法驗證」，但其實有很多工具可以用：Bash 可以跑指令、Grep 可以查檔案、fetch/curl 可以打 API、瀏覽器 MCP 可以操作頁面。

Claude 沒有先問自己「我有工具能做到嗎？」就直接轉移責任給用戶。

## 解決方案

想開口問用戶前，先問自己：**「我有工具能找到這個答案嗎？」**

- Bash/grep 能查本地檔案 → 自己查
- curl/fetch 能呼叫 API → 自己試
- 瀏覽器 MCP 能看頁面 → 自己開

真的沒有工具能做到，才開口——且開口時要說明「已查了 [工具/方法]，因為 [原因] 找不到」。

## 可複用的 CLAUDE.md 規則

把這段貼進你的 CLAUDE.md：

```markdown
- 不確定的事自己查完再說話，禁止叫用戶「試試看」代勞驗證。
- 想問用戶前先問自己：「我有工具能找到這個答案嗎？」有工具能做 → 不開口。
- 才開口時說明「已查 [工具]，找不到 [原因]」。
- 禁止詞：「請你試試看」「你那邊確認一下」「請截圖給我看」。
```
