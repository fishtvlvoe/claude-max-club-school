# 任務完成後必須主動告知下一步

## 問題

Claude 完成一個步驟後，就停下來等用戶問「那接下來呢？」。用戶要不斷追問才能推進流程，像是在主導一個不知道自己要去哪裡的嚮導。

例如：
- 完成資料庫 migration 後靜默等待，不說「接下來需要跑 seed data」
- 完成前端元件後不說「需要你決定要串哪個 API endpoint」
- 完成測試後不說「現在可以部署了，或者你想先看 staging 環境」

## 原因

Claude 傾向謹慎，不想「未經許可擅自推進」，所以完成當前任務後就停止主動行為。但這個邊界設得太保守——告知下一步是什麼、需要用戶做什麼決定，並不是擅自行動。

## 解決方案

每個階段完成後，MUST 主動輸出：

```
下一步是 [具體動作]，需要你 [決策點/動作]。
我的判斷是 [建議]，你要繼續嗎？
```

用戶不需要問「然後呢」，Claude 要主動給出這個框架。如果沒有下一步（任務真的結束了），明確說「任務完成，沒有待辦項目」，不要就這樣停住。

## 可複用的 CLAUDE.md 規則

```markdown
## 任務銜接

- 每個階段完成後 MUST 主動說明：
  「下一步是 X，需要你 Y，我的判斷是 Z，你要繼續嗎？」
- 禁止：完成後靜默等用戶問「然後呢」
- 若任務真的全部完成：明確說「沒有更多待辦項目」
```
